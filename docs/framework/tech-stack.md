# Stack técnico

- Next.js e React com TypeScript.
- Tailwind CSS e CSS de impressão A4.
- Zustand/Immer para o estado do editor existente.
- Supabase para Auth, Postgres e Storage na camada compartilhada.
- Node/npm para scripts, lint, typecheck, testes e build.
- AIOX Core para workflows, stories, gates e governança.

Novas dependências só entram após serem justificadas em uma story ou decisão de arquitetura.

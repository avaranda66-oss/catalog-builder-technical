# Padrões de código

- TypeScript estrito e tipos de domínio explícitos.
- Imports absolutos `@/` em módulos novos.
- Casos de uso puros e adaptadores externos isolados.
- Validação de entrada antes de persistência ou chamada de IA.
- Mensagens de erro acionáveis e sem dados sensíveis.
- Testes de domínio e integração antes de testes de detalhe visual.
- Uma story atualizada com checklist, file list e validação para cada mudança.

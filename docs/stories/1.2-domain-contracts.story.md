# Story 1.2 — Contratos do domínio técnico

**Status:** Done

**Origem:** `docs/briefing.md`, FR-01/FR-02/FR-06/FR-07/FR-08, NFR-03/NFR-04/NFR-05

## História

Como time de produto, quero contratos de domínio compartilhados para produto, documento, mídia, propostas e revisão, para que formulário, planilha, IA, Supabase e exportação validem o mesmo modelo.

## Critérios de aceite

- [x] Produtos e documentos inválidos retornam erros por caminho de campo, sem exceção genérica.
- [x] Blocos de página aceitam apenas os tipos previstos no baseline.
- [x] Propostas exigem origem, produto/catálogo, resumo, mudanças e aceite explícito.
- [x] Mídias carregam metadados suficientes para Storage privado e auditoria.
- [x] Os contratos não mudam componentes visuais nem gravam no Supabase.
- [x] Casos válidos e inválidos têm testes automatizados executáveis sem navegador.

## Notas de implementação

- Contratos ficam em `lib/domain/` e não importam componentes React.
- O schema aceita o conteúdo dinâmico de blocos como dados opacos, mas valida identidade, tipo e ordem.
- Migrations para `documents`, `reviews` e `proposals` ficam em stories de dados posteriores.

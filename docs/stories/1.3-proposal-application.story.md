# Story 1.3 — Aplicação segura de propostas

**Status:** Done  
**Epic:** 1 — Fundação do produto  
**Origem:** `docs/briefing.md`, FR-04/FR-06/FR-07, NFR-04/NFR-05

## História

Como editor técnico, quero aceitar mudanças de importação ou IA individualmente sem sobrescrever uma edição concorrente, para que a revisão preserve a integridade dos dados.

## Critérios de aceite

- [x] Somente mudanças marcadas como aceitas são aplicadas.
- [x] A proposta é aplicada em uma cópia e o alvo original permanece imutável.
- [x] Se o valor atual divergir do `oldValue`, a mudança vira conflito e não é aplicada.
- [x] Caminhos aninhados suportam objetos e índices de array, mas bloqueiam segmentos perigosos.
- [x] A função é independente de React, Zustand, Supabase e qualquer provedor de IA.
- [x] Casos de aplicação, conflito, rejeição e proteção de protótipo são testados.

### Completion notes

A aplicação de propostas agora é um caso de uso puro. Ela clona o alvo, aplica somente mudanças aceitas, compara o valor original com o valor atual e devolve conflitos sem sobrescrita. Caminhos aninhados e arrays são suportados com bloqueio de `__proto__`, `prototype` e `constructor`.

## História

Como editor técnico, quero pesquisar e compor catálogos a partir de uma biblioteca mestre de produtos, para reutilizar dados confiáveis em diferentes publicações sem duplicar cadastros.

## Critérios de aceite

- [x] Inclusão e remoção de produto preservam imutabilidade e não apagam o registro mestre.
- [x] Vínculos duplicados e ordenações incompletas são rejeitados com erro explícito.
- [x] A sincronização calcula anexos, remoções e alterações de ordem de forma idempotente.
- [x] A pesquisa considera SKU, nome, família e dados técnicos, com filtros de família/status.
- [x] Casos de uso não importam React, Zustand ou Supabase.
- [x] Testes cobrem os fluxos principais da biblioteca.

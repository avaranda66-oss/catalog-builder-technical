# Story 3.1 — Aplicação segura no editor visual

**Status:** Done  
**Epic:** 3 — Composição e colaboração  
**Origem:** `docs/briefing.md`, FR-04/FR-07, NFR-01/NFR-04/NFR-05

## História

Como editor técnico, quero que o modal antigo de revisão aplique propostas com proteção contra conflitos, para que a experiência visual permaneça igual e os dados não sejam sobrescritos.

## Critérios de aceite

- [x] O store usa o caso de uso de aplicação segura em vez de escrever caminhos diretamente.
- [x] Mudanças aceitas são aplicadas em cópia e entram no histórico undo/redo.
- [x] Mudanças não aceitas permanecem intactas.
- [x] Conflitos ficam no modal com valor atual e instrução de revisão.
- [x] O layout, a paleta e os controles do baseline não são redesenhados.
- [x] Lint, typecheck e testes continuam passando.

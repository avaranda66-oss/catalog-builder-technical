## Confirmed and corrected

1. **P1 — Mutable request could split saved document and provenance.** `LocalGenerationRepository.write` compared the caller document to staged generation before awaiting SHA-256. A caller mutation during that await changed the saved envelope but retained the original sidecar; write acknowledged success and reopen failed with `SAVED_GENERATION_MISMATCH`. A real-hash test reproduced this without mocked digest behavior. Root captures the submitted request synchronously before awaiting, and also captures generation before asynchronous stage verification. Both snapshot invariants now pass.
2. **P2 — Missing catalog misclassified and exact retry rejected.** `getCatalog` mapped absence to `INVALID_DOCUMENT`; exact repeated create/save mutations returned `CONFLICT`. The reused contract now returns `NOT_FOUND` and acknowledges an exact committed replay without new revision/write. A reused mutation with a different approved payload still fails.
3. **P2 — Initial request ignored.** The first UI implementation checked only nonempty description and always selected the default plan. Root added allowlisted request-to-plan mapping, explicit supported wording and rejection of unsupported requests. Source review confirms this uses typed section ordering and cannot modify technical values.
4. **P2 — Hardcoded provenance footer and internal field IDs.** The first composer claimed source revisions 1–2 for any accepted synthetic input, and the provenance UI displayed internal fact IDs as field labels. Root now derives source IDs/revisions from input and provides human-readable trace labels. The local fixture's longer footer fits in the inspected two-page PDF; arbitrary valid longer source labels remain subject to preflight.
5. **P1 — Cancelled generation could leave the UI permanently busy.** Returning to Library during an awaited generation invalidated its epoch, so its conditional `finally` did not clear `busy`. A later intake could show example/generation buttons permanently disabled. Root explicitly clears processing on cancellation and selects the Library step before awaiting its query. Two independent deferred-promise UI tests pass: a cancelled result cannot install a proposal or disable the next intake, and a late initial Library query cannot overwrite the user's chosen intake. The source fix preceded these tests; no executed RED is claimed for this case.
6. **Physical template finding — 16 mm unit header overflow.** Root's real font/DOM run correctly returned BLOCKED for the unit header on both pages. The composer increases that track to 20 mm while keeping 10 pt text, all rows and table width. For two/three models, fixed tracks total 102 of 176 mm; flex tracks share the remaining 74 mm. For four models, fixed tracks total 90 mm; each model gets 21.5 mm. Every track retains a 16 mm minimum. Independent source review accepts the bounded geometry change; measured final fit remains a browser requirement.

No source change or extra full-suite run was made for this observation.

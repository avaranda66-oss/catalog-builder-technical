## Reproduced counterexamples

1. Fixed row: authored `20 mm = 200000 U`, `uToQ(200000)=4838 Q`, measured requirement `4838 Q`. Browser fit is equality, yet `qToU(4838)=200008 U` made the prior `requiredU > authoredU` test report a false `ROW_CONTENT_OVERFLOW`.
2. Cumulative phase: start prefix `21 U` projects to `1 Q`. Adding scalar `qToU(4838)=200008 U` ends at `200029 U`, which projects to `4838 Q`; the actual row span is only `4837 Q`. A nearest scalar Q→U conversion is therefore not a safe lower-bound for cumulative row projection.
3. Text object: authored width/height `200000 U` project to `4838 Q`. Measured `metrics.widthQ = metrics.heightQ = 4838 Q` fits exactly, while the prior `qToU(metrics.*Q) > authored*U` test falsely reports overflow.

## Authority rule

- Authored geometry and row solver state: `PhysicalLengthU`.
- Chromium-measured geometry: `PhysicalPixelQ`.
- Blocking fit between a rendered measurement and an authored rendered envelope: compare in Q.
- `qToU` remains diagnostic/display approximation or a specifically named conversion semantic. It is not a generic measured-content lower-bound.
- Q remains renderer-only and is never persisted or written back to authored geometry.

## Exact inverse projection

For non-negative row prefixes define:

```text
minimumUForProjectedQ(targetQ)
  = the smallest integer U >= 0 such that uToQ(U) >= targetQ
```

For `targetQ > 0` under the frozen round-half-away-from-zero projection:

```text
minimumUForProjectedQ(targetQ)
  = ceil(((2 * targetQ - 1) * 15875) / 768)
```

The implementation must use safe integer arithmetic and verify minimality (`uToQ(U) >= targetQ` and `U == 0 || uToQ(U-1) < targetQ`). This is an inverse of the monotone projection predicate, not a nearest scalar round-trip.

## Row constraint model

For each row, authored/base U is:

```text
AUTO     -> 0 U
MIN_MM   -> minMm in U
FIXED_MM -> authored height in U
```

Every measured cell, including `rowSpan=1`, remains a Q constraint:

```text
requiredQ = intrinsicContentHeightQ + paddingTopQ + paddingBottomQ
```

Let `basePrefixU[k]` be cumulative authored/base U at row boundary `k`. Enumerate only growable AUTO/MIN rows. Let `E[j]` be cumulative extra U assigned to the first `j` growable rows and `g(k)` the number of growable rows before boundary `k`.

```text
totalBoundaryU[k] = basePrefixU[k] + E[g(k)]
```

A cell over `[start,end)` must satisfy:

```text
uToQ(totalBoundaryU[end]) - uToQ(totalBoundaryU[start]) >= requiredQ
```

If the interval contains a growable row, `a=g(start) < b=g(end)`. Once `E[a]` is known, the exact minimal end target is:

```text
targetEndU = minimumUForProjectedQ(
  uToQ(basePrefixU[start] + E[a]) + requiredQ
)

E[b] >= targetEndU - basePrefixU[end]
```

Together with `E[j+1] >= E[j]`, these are forward edges in growable-prefix order. Compute each `E[b]` as the maximum of its chain predecessor and all incoming interval lower bounds.

## Mathematical and deterministic justification

Every edge ends after its source, so its source prefix is final before the edge is evaluated. `uToQ` and `minimumUForProjectedQ` are monotone. By induction, any feasible solution must have each growable prefix at least the constructed prefix: the chain lower-bound is unavoidable, and every interval lower-bound evaluated at any larger feasible source is at least the lower-bound evaluated at the constructed source. The constructed vector therefore is componentwise minimum, minimizes total extra U exactly, and cannot depend on constraint iteration order.

Only differences `E[j+1]-E[j]` are assigned to growable rows. FIXED rows never receive extra U. A span containing no growable row is validation-only: the solver does not grow unrelated rows before the span merely to change quantization phase.

## Mandatory postcondition

After final U heights are projected through cumulative boundaries, preflight re-checks every rendered cell:

```text
availableContentQ = boundaryQ[end] - boundaryQ[start]
                  - paddingTopQ - paddingBottomQ

intrinsicContentHeightQ <= availableContentQ
```

If an all-FIXED span violates this, emit `ROW_CONTENT_OVERFLOW / ERROR`. If a span containing AUTO/MIN still violates it, the row solver failed; publication remains blocked. No silent clipping is permitted.

## Text object fit

Text objects compare the measured Q facts directly with the authored frame projection:

```text
metrics.widthQ  > uToQ(authoredWidthU)  -> TEXT_OBJECT_OVERFLOW
metrics.heightQ > uToQ(authoredHeightU) -> TEXT_OBJECT_OVERFLOW
```

Equality in Q fits.
